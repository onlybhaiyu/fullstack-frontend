Features

Everything You Need to Manage Information

A complete set of tools to create, read, update, and delete personal records — with a clean UI and secure backend integration.

🔐

Secure Authentication

Cookie-based sessions with HttpOnly protection. No passwords stored in the browser. Google Sign-In ready for future integration.

📋

Full CRUD Operations

Create, read, update, and delete user records through a clean form interface connected to a RESTful backend API.

📊

User Dashboard

View all records in a searchable, sortable table. Quick actions for edit and delete. Real-time refresh from the API.

📱

Responsive Design

Looks great on desktop, tablet, and mobile. Adaptive sidebar navigation and fluid layouts for any screen size.

⚡

Fast & Lightweight

Zero JavaScript frameworks. Pure HTML, CSS, and vanilla JS — instant load times served directly by Nginx with no build step.

🔗

API Ready

All endpoints are wired and documented. Drop in your Flask backend and everything connects automatically through Nginx's reverse proxy.

How It Works

Up and Running in 3 Steps

Simple to deploy, simple to use. Your data is always in your control.

1

Create an Account

Register with your name and email. Your credentials are verified by a secure backend and session cookies keep you signed in.

2

Add Your Information

Use the profile form to enter your name, email, age, phone, city, and country. Data is saved directly via REST API.

3

Manage from Dashboard

View, search, edit, or delete any record from the dashboard table. Changes are reflected instantly from the live API.
